# Legal Contract Skill TR

A contract-review and rubric-generation project built on multiple legal skill sets.  
This repository combines two legal skill libraries into one workflow, then uses the OpenRouter API to:

- batch-review contracts,
- generate common drafting mistakes,
- and produce reusable contract review rubrics.

---

## Project Goals

- Combine legal review skills from different skill collection set.
- Batch-review existing contract data and output markdown reports
- Build reusable knowledge artifacts for drafting and review quality control
- Provide a scalable workflow for larger contract QA efforts

---

## TL;DR

**In short:** if you only want the key takeaways, focus on these two files in `contract-review-skills-summary/`:

- `contract-review-rubrics.md`
- `contract-writing-common-mistakes.md`

## Key Structure

- `ai-legal-claude-main/`: legal skills (`review`, `risks`, `missing`, `negotiate`, etc.)
- `claude-legal-skill-main/`: primary `contract-review` skill
- `contract-review-skills-summary/`: consolidated outputs
  - `CONTRACT-REVIEW-SKILLS.md`
  - `contract-writing-common-mistakes.md`
  - `contract-review-rubrics.md`
- `contracts_2020_sample.json`: 2020 contract sample input (batch review)
- `combined_contracts_penalty_term.json`: perturbed contract dataset generated by injecting risk-related terms based on skill-defined risk patterns
- `merged_contracts_by_skill.json`: superficial-leval perturbed contract dataset
- `contracts_2020_reviews/`: generated review reports (`.md`) + `summary.json`
- `review_contracts_openrouter.py`: batch contract review script
- `generate_skills_artifacts_openrouter.py`: mistakes/rubrics generation script

## Requirements

- Python 3.9+
- OpenRouter API key

Install dependencies:

```bash
pip3 install -r requirements.txt
```

Set environment variables (see `.env.example`):

```bash
export OPENROUTER_API_KEY="your_openrouter_api_key_here"
export OPENROUTER_BASE_URL="https://openrouter.ai/api/v1"
export OPENROUTER_MODEL="anthropic/claude-opus-4.6"
```

Note: `review_contracts_openrouter.py` currently defaults to `minimax/minimax-m3`, so pass `--model` (or set `OPENROUTER_MODEL`) if you want a different model.

## Quick Start

### 1) Batch Contract Review

Run a small test:

```bash
python3 review_contracts_openrouter.py --limit 2 --model anthropic/claude-opus-4.6
```

Run full batch with resume/retry controls:

```bash
python3 review_contracts_openrouter.py \
  --resume \
  --delay 2 \
  --retries 5 \
  --continue-on-error \
  --model anthropic/claude-opus-4.6
```

Useful options:

- `--preset {minimal,workflow,full}`: choose loaded skill bundle
- `--skills ...`: manually specify skill IDs (overrides preset)
- `--limit` / `--start`: chunk processing
- `--resume`: skip already-generated reports
- `--continue-on-error`: continue batch after single-item failures

---

### 2) Generate Reusable Artifacts (Mistakes + Rubrics)

Generate both files:

```bash
python3 generate_skills_artifacts_openrouter.py --model anthropic/claude-opus-4.6
```

Generate only one:

```bash
python3 generate_skills_artifacts_openrouter.py --mistakes-only --model anthropic/claude-opus-4.6
python3 generate_skills_artifacts_openrouter.py --rubrics-only --model anthropic/claude-opus-4.6
```

Default output paths:

- `contract-review-skills-summary/contract-writing-common-mistakes.md`
- `contract-review-skills-summary/contract-review-rubrics.md`

## Outputs

### Contract Review Outputs

- One markdown report per contract (risks, key terms, missing protections, negotiation priorities, etc.)
- `summary.json` captures run metadata (model, counts, errors, previews)

### Knowledge Artifacts

- **Common Mistakes**: contract drafting mistakes and better practices
- **Rubrics**: reusable scoring dimensions, weights, and quick-scan checks
